👀 Look & Learn: The File Structure

Websites are fragile ecosystems. If you move a file, you break the link. Every project gets its own named folder. The file inside is always index.html. Images live inside their own project — not in a shared course folder. Here is how your computer should look by the end of today:

Documents/
└── ADD103/                        <!-- Root Course Folder -->
    │
    ├── manifesto/                 <!-- Project folder (named after the project) -->
    │   ├── index.html             <!-- Always index.html inside -->
    │   └── images/                <!-- Images belong to THIS project -->
    │
    ├── about-me/                  <!-- Next project will get its own folder -->
    │   ├── index.html
    │   └── images/
    │
    └── portfolio/                 <!-- Final project will live here -->
        ├── index.html
        └── images/
The Three Rules:
  • No Spaces: Use about-me or week_01 — never about me. Servers don't handle spaces well.
  • Lowercase Only: index.html not Index.HTML. Case mismatches cause 404 errors on live servers.
  • index.html is always the homepage: Servers look for this filename automatically. Every project folder gets one.

📘 The Emmet Shortcut: Never Type Boilerplate Again

VS Code comes with a built-in tool called Emmet. It writes repetitive HTML for you. The most important shortcut you will learn today:

1. Create a new file named  index.html
2. On the first empty line, type:   !
3. Press:  Tab
4. The entire HTML boilerplate appears instantly.

Emmet generates this for you — you do not type it from scratch:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>

</body>
</html>

Your only job: change <title>Document</title> to something meaningful, then start writing content inside <body>.

💻 Project: The Developer Manifesto

We are going to start this semester by setting your intentions. You will create a webpage that lists your goals for this course.

Step 1: Install VS Code

⚙️ One-time install (do this before anything else):
  1. Go to code.visualstudio.com and download VS Code for your operating system. It is free.
  2. Run the installer. Accept all defaults.
  3. Open VS Code. Take a look around — we will use this every single week.

Step 2: Create Your Project Folder

  1. Open your Documents folder. Create a new folder named ADD103 (no spaces).
  2. Inside ADD103, create a folder named manifesto (lowercase).
  3. In VS Code: File → Open Folder → select the manifesto folder.
  4. In the Explorer panel (left sidebar), click the New File icon → name it index.html.

Step 3: Use Emmet to Generate the Boilerplate

  1. Click inside your empty index.html file.
  2. Type ! (just the exclamation mark).
  3. Press Tab.
  4. The full HTML boilerplate appears instantly. Change the <title> to My Developer Manifesto.

Step 4: Write Your Content

Inside the <body> tags, answer these four questions using <h1> and <p> tags:

<h1>Hello World. My name is [Your Name].</h1>

<p>I am taking this course because [Reason].</p>

<p>By the end of this semester, I want to build a website about [Topic].</p>

<p>My "power animal" for getting through hard code is a [Animal] because [Reason].</p>

Step 5: View in the Browser

  1. Save the file: Ctrl+S (Windows) or Cmd+S (Mac).
  2. Open your Documents → ADD103 → manifesto folder in Windows Explorer or Finder.
  3. Double-click index.html. It opens in your browser. That's your first web page.
  4. Go back to VS Code, make a change, save, then refresh the browser to see it update.

📌 In Week 1B we will look at more HTML tags. In Week 4 we will put this project on GitHub so you always have a backup in the cloud.
