👀 Look & Learn: The File Structure

Websites are fragile ecosystems. If you move a file, you break the link. Maintaining a strict structure is critical. Here is how your computer should look by the end of today:

Documents/
└── ADD103/                      <!-- Root Course Folder -->
    ├── week_01/                 <!-- Subfolder for this week -->
    │   └── manifesto.html       <!-- Your assignment -->
    │
    ├── week_02/                 <!-- Future folders... -->
    │
    └── images/                  <!-- Dedicated folder for media -->
Observation:
  • No Spaces: Notice we use ADD103 and week_01 (underscores). Computers hate spaces in filenames.
  • Lowercase: We prefer lowercase filenames (`manifesto.html`). It prevents server errors later.

📘 Detailed Example: First Live HTML File

Copy this full starter file into manifesto.html. The comments explain exactly what each line does.

<!doctype html>
<html lang="en">
<head>
    <!-- Ensures emoji and symbols render correctly -->
    <meta charset="UTF-8">
    <!-- Makes layout scale correctly on phones -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Developer Manifesto</title>
</head>
<body>
    <!-- Main heading for users and screen readers -->
    <h1>Hello World. My name is [Your Name].</h1>

    <!-- Core reflection content -->
    <p>I am taking this course because [Reason].</p>
    <p>By the end of this semester, I want to build a website about [Topic].</p>

    <!-- Deployment proof line so you can confirm updates live -->
    <p>Deployment timestamp: [Date]</p>
</body>
</html>

💻 Project: The Developer Manifesto

We are going to start this semester by setting your intentions. You will create a webpage that lists your goals for this course.

Step 1: The Setup

  1. Log in to your personal InMotion cPanel account and open File Manager.
  2. Create your ADD103/week_01 folder structure.
  3. Create a new file named manifesto.html.

Step 2: The Content

Type the following HTML into your file, but fill in the bracketed info with your own answers:

Hello World. My name is [Your Name].

I am taking this course because [Reason].

By the end of this semester, I want to build a website about [Topic].

My "Power Animal" for coding is a [Animal] because [Reason].

Step 3: The Verification

  1. Save the file.
  2. Find the file in your actual folder (Finder/Explorer).
  3. Double-click it to open it in Chrome.
  4. Does it look right? (It will be plain text, that is expected!)
