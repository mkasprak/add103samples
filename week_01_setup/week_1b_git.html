The Logic:
  • public_html: The folder the web server actually publishes.
  • Path Discipline: Folder names and file names must match exactly.
  • Verification: Every upload must be tested at the live URL.

💻 Project: First Live Publish

You will publish your first working page to your personal hosting account.

Phase 1: The Launch

  1. Log in to cPanel and open File Manager.
  2. Create folders: public_html/ADD103/week_01.
  3. Upload manifesto.html from Lesson 1A into week_01.
  4. Set folder permissions to 755 if needed.
  5. Open your live URL and verify the page loads with no 403/404 errors.

Phase 2: The Update (Publish Again)

A website is never finished. Publish an update to prove your workflow.

  1. Back on your computer, open `manifesto.html`.
  2. Add a new line at the bottom: "Timestamp: I have successfully deployed this site on [Date]!"
  3. Save, then re-upload the updated file to the same cPanel folder.
  4. Go to your live URL. Refresh the page.

Did the new text appear? If so, you have mastered the infinite loop of web development.
