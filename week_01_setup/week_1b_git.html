👀 Look & Learn: The Deployment Pipeline

This is how your code travels from VS Code to the live internet — and it’s the same pipeline professionals use.

VS Code (Your Laptop)
↓ git push

GitHub.com (The Cloud Backup)
↓ cPanel pulls your latest commit

public_html/ADD103/ (Your Server)
↓
Live Website URL
How it works:
  • git push: Sends your saved code from your computer to GitHub.
  • cPanel Git Version Control: A tool in your hosting dashboard that watches your GitHub repo and copies new commits to your live server.
  • public_html: The folder your web server reads. Files in here are visible at your live URL.
  • You only do the cPanel setup once. After that, push → pull → live is your entire workflow.

💻 Project: First Live Publish

We set up the connection once, then prove it works by pushing an update.

Phase 1: Set Up cPanel Git Version Control

  1. Log in to your InMotion cPanel account (your instructor will provide your login URL and credentials).
  2. In the Files section, click Git Version Control.
  3. Click the blue Create button.
  4. Toggle “Clone a Repository” to ON.
  5. In the Clone URL field, paste your GitHub repo URL:
    https://github.com/yourusername/ADD103.git
  6. In the Repository Path field, type:
    /home/youraccount/public_html/ADD103
    (Replace youraccount with your cPanel username — visible in the top-right of the cPanel dashboard.)
  7. Click Create. cPanel will download your GitHub repo to the server. You’ll see a green success message.
  8. Click Manage → the Pull or Deploy tab → click “Update from Remote”.
  9. Open your live URL in a new tab:
    https://yourdomain.com/ADD103/manifesto.html
    Does your Manifesto page load? If yes — 🎉 you’ve deployed your first website.

Phase 2: Prove the Workflow (Push an Update)

A website is never finished. Let’s confirm your full loop works — edit, push, pull, live.

  1. Back in VS Code, open manifesto.html.
  2. Add this line at the bottom of your <body>:
    <p>Deployed on [Date]. The pipeline works!</p>
  3. Save (Ctrl+S). Then in the VS Code Terminal:
git add .
git commit -m "Add deployment timestamp"
git push
  1. Go back to cPanel → Git Version Control → Manage → Pull or Deploy → Update from Remote.
  2. Refresh your live URL. Did the new timestamp line appear? ✅ You have now mastered the infinite loop of web development.
💡 Pro Tip: Bookmark these two tabs. You will open them every single week:
1️⃣ Your GitHub repo — to confirm your push arrived.
2️⃣ cPanel Git Version Control — to pull it live.
