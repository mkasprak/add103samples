Week 3B: The Box Model

ADD 103: Introduction to Web Design | Spring 2026
🎯 Learning Objective Alignment: Styling (LO2) — "Demonstrate an understanding of the CSS Box Model (margin, border, padding)."

Overview

In web design, everything is a box. Every paragraph, every header, every image is inside a rectangular box.

Today, we learn the most important concept in layout: The Box Model. Mastering margins, padding, and borders is the difference between specific design and a messy pile of text.

✨ Why this matters

This is the leading cause of "Why doesn't my button look right?" frustration. If you don't understand the difference between Padding (Inner Space) and Margin (Outer Space), you will struggle to lay out even simple pages.

📖 The Textbook: Inside the Box

Click below to unbox the layers.

1. Content (The Center)

What is it? The actual text or image you see.

Controlled by: width and height.

2. Padding (Inner Space)

What is it? The space between the content and the border.

Padding clears an area around the content. It is inside the box background color.

Think of it like bubble wrap protecting the item inside the box.

3. Border (The Edge)

What is it? A line that goes around the padding and content.

Code: border: 1px solid black;

4. Margin (Outer Space)

What is it? The space outside the border.

Margin separates this element from its neighbors. It is transparent.

Think of it like the personal space bubble between two people.

👀 Look & Learn

See how Padding and Margin affect the layout of two cards.

/* The Card Style */
.card {
    background-color: lightblue;
    border: 2px solid darkblue;
    
    /* PADDING: pushes the text AWAY from the border */
    padding: 20px;

    /* MARGIN: pushes the whole card AWAY from other cards */
    margin-bottom: 30px;
    
    width: 300px;
}
Observation:
  • Without padding, the text would be uncomfortably stuck to the border line.
  • Without margin, the cards would touch each other.
🗣️ Discussion: Margin vs Padding

It's the most common confusion for new developers.

Prompt: Find a physical object in your room (like a framed picture or a book). Describe it using Box Model terms. What is the content? What is the padding? What is the border? Share your analogy in the Canvas Discussion board.

💻 Project: The Product Collection

You have been hired to build a product display for an e-commerce store. You need to build a row of 3 identical "Product Cards".

📋 Directions

  1. Class vs ID: Because we are making multiple cards, you must use a Class (.product-card), not an ID.
  2. HTML Structure: Create 3 `div`s, each with the class `product-card`. Inside each, put an `h3` (Product Name), a `p` (Description), and a `button` (Buy Now).
  3. The CSS Challenge:
    • Give the cards a border and a background color.
    • Add 20px padding so the text isn't cramp.
    • Add 20px margin so the cards have space between them.
    • Make the button look clickable (add padding to the button itself!).
Pro Tip: Professional designers use "rem" instead of "px" for padding. Try using padding: 1rem; instead of 16px. It scales better!
