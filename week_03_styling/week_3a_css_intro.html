Overview

HTML provides the structure, but CSS (Cascading Style Sheets) provides the voice. The fonts you choose, the colors you apply, and the size of your text dramatically change how a user "hears" your content.

Today, we will learn the basics of CSS selectors and dive deep into Typography, including how to import professional fonts from Google.

📖 The Textbook: CSS Basics

Click below to understand how the browser decides what to show.

1. The Syntax (Rule Set)

Selector: Who are we styling? (e.g., `h1`)

Property: What are we changing? (e.g., `color`)

Value: How are we changing it? (e.g., `blue`)

Example: h1 { color: blue; }

2. Defining Typography

Text is styled using specific properties:

  • font-family: The font itself (e.g., "Arial", "Times New Roman").
  • font-size: How big? (e.g., 16px, 1.5rem).
  • font-weight: How thick? (e.g., bold, normal, 700).
  • text-align: Alignment (left, center, right).
3. The "Cascade" (Priority)

What happens if one rule says "Make H1 Blue" and another says "Make H1 Red"?

The Cascade decides. Generally, the rule that comes last wins. It flows down like a waterfall. Specificity (IDs vs Classes) also plays a big role.

Step 1: The Setup (HTML)

First, you must "import" the font. This always goes in the <head> of your HTML file, usually before your own stylesheet.

<head>
    <!-- 1. Connect to Google Fonts -->
    <link rel="preconnect" href="https://fonts.googleapis.com">
    <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
    
    <!-- 2. Load the specific font (e.g., Roboto) -->
    <link href="https://fonts.googleapis.com/css2?family=Roboto:wght@400;700&display=swap" rel="stylesheet">

    <!-- 3. Link your own CSS last -->
    <link rel="stylesheet" href="style.css">
</head>

Step 2: The Usage (CSS)

Now that the browser has downloaded the font, you can ask for it in your CSS.

/* Apply Roboto to everything */
body {
    font-family: 'Roboto', sans-serif;
}

/* Or just to headers */
h1 {
    font-family: 'Roboto', sans-serif;
    font-weight: 700; /* Use the bold version */
}
Note: We always include sans-serif as a backup. If Google crashes (unlikely), the browser will use its default cleaner font.

💻 Try It Yourself: The Style Guide

You are going to create a "Brand Style Guide" page to experiment with typography.

Step 1: The Content (HTML)

  1. Create style-guide.html and `style.css`.
  2. Link them together.
  3. In HTML, write an <h1> that says "My Brand Styles".
  4. Write an <h2> for "Sub-Heading Example".
  5. Write two <p> paragraphs with dummy text (Lorem Ipsum).

Step 2: Google Fonts (Required)

  1. Go to fonts.google.com.
  2. Search for a font you like (e.g., 'Open Sans', 'Lato', 'Merriweather').
  3. Click "Get Font" > "Get Embed Code".
  4. Copy the code they give you and paste it into the <head> of your HTML.

Step 3: The Style (CSS)

In your CSS file, implement the following requirements:

  1. Global: Set the body to use your new Google Font.
  2. Background: Use a light background color (e.g., #f0f0f0).
  3. H1: Make it Centered, Large (3rem), and a deep color (Navy, DarkRed, etc.).
  4. H2: Give it a bottom border and a different color than the H1.
  5. P: Make the font size 1.1rem and increase line-height to 1.8.

Self-Check: Does your page look "designed" or does it still look like default browser styles?
