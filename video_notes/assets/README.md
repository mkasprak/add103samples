# video_notes/assets/

This folder holds visual assets used in Gemini video production.

## How to use these files

1. Open the `.html` file in your browser
2. Make it full screen (F11)
3. Screenshot it (Snipping Tool or Win+Shift+S)
4. Save the screenshot with the filename listed below
5. Upload the screenshot alongside your Gemini prompt

## Screenshot tips

- Use **Win + Shift + S** on Windows to capture a clean region
- Capture just the white card — not the dark browser chrome around it
- Save at full resolution — Gemini will scale it as needed
