# 🚀 The AI Course Architect: Genesis Kit

**Version:** 1.0 (The "Jeanie" Release)
**Created by:** Meri Kasprak & Gemini
**Goal:** To allow any educator to rapidly build high-quality, standardized curriculum using AI.

---

## 👋 What is this?
You have not just downloaded a set of folders; you have downloaded an **Operating System for your Course**.

This kit is designed to "train" an AI Assistant (like Gemini, Copilot, or ChatGPT) to become your **Lead Architect**. It provides the AI with:
1.  **A Persona ("Jeanie"):** A consistent voice for your students.
2.  **Templates:** Blueprints for every lesson, so you never start from a blank page.
3.  **Strict Rules:** A file system that keeps your course organized automatically.

---

## 🛠️ Installation

1.  **Copy the Folder:**
    *   Take the folder named `_COURSE_GENESIS` and copy it into the root directory of your new class (e.g., `Documents/My_PowerBI_Class/`).
2.  **Rename the Folder:**
    *   Rename `_COURSE_GENESIS` to `_ARCHITECT` (or keep it as is, but `_ARCHITECT` looks cooler).
3.  **Open in VS Code:**
    *   Open your class folder in VS Code.

---

## 🚦 How to Start the Engine (The Bootloader)

This is the magic step. You don't tell the AI what to do from scratch; you just "boot" the system.

1.  **Open Chat:** Open your AI Assistant's chat window in VS Code.
2.  **Open the File:** Open the file `00_START_HERE.md` inside the kit.
3.  **Copy & Paste:** Copy the entire text of that file and paste it into the chat.
    *   *System Response:* The AI will read your files, understand the rules, adopt the persona, and ask for your Syllabus.
4.  **Feed the Syllabus:** Paste your course outline or syllabus. The AI will immediately start building your "Project Status Grid."

---

## 🏗️ The Workflow

Once the system is running, your workflow becomes simple:

1.  **Pick a Topic:** Look at your new `project_status.md` and pick an empty row (e.g., "Assignment 3A").
2.  **Command the AI:** "Architect, please build Assignment 3A using the HTML Template."
3.  **Refine:** The AI will generate the file following your strict standards.
4.  **Repeat:** Move to the next row.

---

## 🧠 Why "Jeanie"? (The Pedagogy)
This system uses a "Good Cop / Bad Cop" structure defined in `specs/pedagogy.md`:
*   **The Architect (AI in Chat):** Professional, organized, handles file management.
*   **Jeanie (AI in Content):** Friendly, uses emojis, helps students debug.

*You can change these personas by editing `specs/pedagogy.md`!*
