Detailed Example: QA Report Entry Format

Issue 1: Broken navigation link
- Page tested: about.html
- Reproduction steps: Click "Contact" in main nav
- Expected: Opens contact.html
- Actual: 404 error
- Suggested fix: Update href to "contact.html"

Issue 2: Mobile text overflow
- Page tested: index.html at 375px width
- Reproduction steps: Load homepage and inspect hero heading
- Expected: Heading wraps within viewport
- Actual: Heading overflows right edge
- Suggested fix: Add media query reducing h1 size on small screens

Issue 3: Low contrast button text
- Page tested: pricing.html
- Reproduction steps: View CTA button in hero section
- Expected: Readable text contrast
- Actual: Pale text on light yellow button
- Suggested fix: Darken text color to #1f2937
