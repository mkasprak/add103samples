My Web Manifesto

By: Alex Rivera

Why I'm Here

I'm taking this course because I want to build things on the internet — not just use them. The web has always felt like a place where ideas come to life, and I want to be someone who creates that.

What I Believe About the Web

  • The web should be accessible to everyone, regardless of ability or device.
  • Good design is honest — it doesn't trick or mislead.
  • Simple, clean code is something to be proud of.
  • Every website tells a story. The best ones tell it clearly.

What I Hope to Build

By the end of this course, I want to be able to:

  1. Build a complete website from scratch using HTML and CSS.
  2. Understand how layout actually works — not just guess until it looks right.
  3. Create pages that look good on any screen size.
  4. Have a project I'm proud to show people.

My Biggest Fear

Honestly? Getting lost. There's so much to learn and I worry about falling behind. But I'm committing to asking questions, practicing outside of class, and not skipping the small stuff.

One Thing I Already Know

I know that every expert was once a beginner. The only way to get good at this is to build things, break things, and figure out why.
