🎯 Learning Objective Alignment: Structure (LO1) — "Incorporate hyperlinks and images, ensuring accessibility through alt attributes."

Overview

The "Web" is named for its connections. Without links, the internet is just a collection of lonely documents. Without images, it is just a wall of text.

Today, we will master the Anchor Tag (<a>) and the Image Tag (<img>), while learning the critical importance of file paths.

♿ Accessibility Note: Images MUST have an alt attribute. This text describes the image to blind users. Without it, a screen reader just says "Image" (which is useless).

📖 The Textbook: Connecting Content

1. The Anchor Tag (<a>)

Use: Creates a hyperlink to another page or site.

Key Attribute: href="..." (Hypertext Reference). This is the destination.

Mnemonic: "Anchor to Href (Hypertext reference)."

Opening in New Tabs: Use target="_blank" for external links (like Google) so you don't lose your user.

2. The Image Tag (<img>)

Use: Embeds an image file.

Attributes:

  • src="...": The source path (Where is the file?).
  • alt="...": Alternative text (What is the picture?).

Note: The <img> tag is self-closing. It has no closing tag.

3. Understanding Paths (Relative vs. Absolute)

Absolute Path: A full URL like https://google.com. Use this for other peoples' websites.

Relative Path: A local path like images/cat.jpg. Use this for your own files.

Tip: ../ means "Go up one folder".

👀 Look & Learn

Observe how we link to Google (external) vs linking to our own contact page (internal), and how we display an image.

<!-- 1. TEXT LINKS -->
<p>
    Visit <a href="https://google.com" target="_blank">Google</a> for search.
    Or, go to my <a href="contact.html">Contact Page</a>.
</p>

<!-- 2. IMAGE -->
<!-- 
     src: Look inside 'images' folder, find 'logo.png'
     alt: Description for screen readers
-->
<img src="images/logo.png" alt="McHenry County College Logo" width="200">

<!-- 3. IMAGE AS A LINK -->
<a href="index.html">
    <img src="images/home-icon.png" alt="Go to Home">
</a>
Observation:
  • target="_blank" forces the link to open in a new tab. Great for external links!
  • Notice the image path images/logo.png. This only works if you actually have a folder named 'images'.

💻 Project: The Multimedia Resume

Transform your "Semantic Biography" into a fully connected, multimedia experience.

📋 Directions

  1. Images: Create an images subfolder. Download a photo of yourself (or a placeholder avatar) and save it there.
  2. Embed: In your "About Me" section, use an <img> tag to display your photo.
    • Requirement: You MUST include an alt description.
  3. External Links: Creating a "Socials" list. Add links to 3 external sites (e.g., LinkedIn, GitHub, MCC Home Page).
    • Requirement: These MUST open in a new tab using target="_blank".
  4. Internal Links: Create a new file called portfolio.html (it can be blank for now). Add a link in your bio that says "View my Portfolio" that points to this file.
Test your paths: Breaking links is the #1 error in this course. Click every single link before you submit. If you get a "File Not Found", check your spelling.
