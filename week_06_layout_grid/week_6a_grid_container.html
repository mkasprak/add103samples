Overview

Flexbox (Week 5) is great for rows (1-Dimension). But what if you want a checkerboard? Or a magazine layout with blocks of different sizes? You need CSS Grid.

Grid is the most powerful layout system in web history. It allows us to draw a blueprint of rows and columns, and then drop content into specific slots.

♿ Accessibility Note: Just like Flexbox, Grid rearranges items visually. Ensure your HTML source code is in a logical order (Heading first, Navigation second, Content third) regardless of where they sit on the screen.

📖 The Textbook: Columns & Rows

To start a Grid, you turn the Parent Container into a Grid, and then define your tracks.

1. Defining Columns (grid-template-columns)

This property tells the browser how many columns you want and how wide they are.

  • grid-template-columns: 200px 200px; (Two fixed columns).
  • grid-template-columns: 1fr 1fr 1fr; (Three equal flexible columns).
  • grid-template-columns: 30% 70%; (A Sidebar breakdown).

The "fr" Unit: "Fraction". 1fr means "1 part of the available space". It is better than percentages because it handles margins automatically.

2. The Gap (grid-gap)

In the old days, adding space between columns broke the math. In Grid, it's free.

gap: 20px;

This adds 20px of empty space (gutters) between every row and column. It does NOT add space to the outside edges.

3. The Repeat Function

Tired of typing 1fr 1fr 1fr 1fr 1fr?

Use repeat(5, 1fr). This tells the browser: "Give me 5 columns, all 1 fraction wide."

👀 Look & Learn: The 3-Column Card Layout

This is the standard "Services" or "Features" section of every corporate website.

🔗 View Live Sample: The Daily News 
/* THE PARENT (The Grid) */
.services-grid {
    display: grid;
    /* Create 3 equal columns */
    grid-template-columns: repeat(3, 1fr);
    gap: 30px; /* Nice big gutters */
}

/* THE CHILDREN (The Cards) */
.card {
    background: #f4f4f4;
    padding: 20px;
    border: 1px solid #ddd;
}
Observation:
  • We didn't set a width on the cards! The Grid logic handles it.
  • If we wanted 4 columns, we just change the 3 to a 4. The CSS handles the math for us.

💻 Project: The Photo Wall

We are building a dense wall of photos (Pinterest style).

📋 Directions

  1. Structure:
    • Create a `div` class photo-wall.
    • Inside, put 6 image tags (use Placehold.co or Unsplash).
  2. The Grid:

    📘 Detailed Example: Grid Container Tracks

    This setup creates a clean two-column layout with explicit control over columns and spacing.

    .layout {
    display: grid;                          /* Turns container into grid */
    grid-template-columns: 240px 1fr;       /* Sidebar + flexible content */
    grid-template-rows: auto 1fr auto;      /* Header, content, footer */
    gap: 1rem;
    min-height: 100vh;
}

.header {
    grid-column: 1 / -1; /* Span all columns */
}

.footer {
    grid-column: 1 / -1; /* Footer also spans all columns */
}

    Example Walkthrough: Defining grid tracks and spanning rows/columns
    (User to embed Panopto/YouTube Iframe here)
    • Set `.photo-wall` to display: grid;.
    • Set columns to repeat(3, 1fr). (3 Columns).
    • Add a gap: 15px;.
  3. The Images:
    • Images often misbehave in grids. Set your images to width: 100%; height: 100%; object-fit: cover; so they fill their grid cells perfectly without stretching.
Pro Tip: object-fit: cover; is magic. It crops the image to fit the box, rather than squishing it.
