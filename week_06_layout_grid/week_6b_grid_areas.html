📖 The Textbook: Child Properties

1. Grid Column (Spanning)

You can tell a child to stretch across multiple lines.

  • grid-column: span 2; (Make this item 2 columns wide).
  • grid-column: 1 / -1; (Start at line 1, end at the last line. Full width!).
2. Grid Row (Height Spanning)

Same thing, but vertical.

  • grid-row: span 2; (Make this item 2 rows tall).

👀 Look & Learn: The "Magazine" Layout

Notice how Item 1 dominates the layout.

.magazine-grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 10px;
}

.feature-article {
    /* Span 2 cols wide, 2 rows tall */
    grid-column: span 2;
    grid-row: span 2;
    background: gold;
}

.minor-article {
    background: #eee;
}
Observation:
  • The `.feature-article` becomes a big square block.
  • The `.minor-article` items will automatically flow around it to fill the empty gaps.

  4. The Spanning Logic:
    • Target `.main-display`: This needs to be BIG. Make it span all 5 columns (grid-column: 1 / -1;). Increase its height (e.g., 400px).
