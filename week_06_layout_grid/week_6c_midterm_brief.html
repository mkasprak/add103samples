📅 Phase 1: Planning (Due Week 6)

Before you write code, you must write a plan. "Winging it" leads to messy code and broken layouts.

Deliverable: The Design Doc

Submit a PDF or Markdown file answering the following:

  1. The Topic: What is your site? (e.g., A Local Bakery, A Portfolio, A Fan Site).
  2. The Audience: Who is visiting? (e.g., Hungry customers looking for hours).
  3. The Sitemap: List your 3+ pages (e.g., Home, Menu, Contact).
  4. The Wireframe: A rough sketch (pencil/paper is fine) of your Homepage layout. Label your "Grid Areas" and "Flex Containers".

🏗️ Phase 2: The Build (Due Week 8)

Your site must meet these technical specifications. Treat this like a client contract.

1. Technical Specs
  • 3+ HTML Pages: Linked together via a Navigation Bar.
  • External CSS: One generic `styles.css` file shared by all pages.
  • Layout: Must use Flexbox for the Navigation and Grid for the Main Content.
  • Responsiveness: Must have at least ONE breakpoint (Mobile View vs Desktop View).
2. Code Quality
  • Semantic HTML: Use `header`, `nav`, `main`, `footer`, `section`.
  • No ID Styling: Use Classes for CSS styling. Keep IDs for JS hooks only.
  • Validation: Code must pass the W3C Validator.

🚀 How to Start

Don't panic. Follow this order:

  1. Folder Setup: Create `midterm_project` folder. Add `index.html`, `style.css`, and `images/`.
  2. Content First: Write the HTML for all 3 pages. Don't touch CSS yet. Just get the text and images on the screen.
  3. Mobile Layout: Add CSS. Make it look good on a narrow screen (1 Column).
  4. Desktop Layout: Add your `@media` query. Create your Grid columns.
  5. Polish: Add colors (Variables!), fonts (Google Fonts), and hover states.

⛏️ Dig Deeper: Example Topics

  • The "Local Gem": Pick a real small business in McHenry County (Coffee shop, library) and redesign their site.
  • The "Hobby Hub": A site dedicated to a passion (Vintage Cameras, Hiking Trails, Indie Games).
  • The "Resume Site": Get a head start on your final portfolio.
