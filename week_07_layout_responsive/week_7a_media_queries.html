Overview

In 2010, Ethan Marcotte coined the term "Responsive Web Design." Before that, we built two websites: one for computers, and one specifically for "m.dot" phones. It was a maintenance nightmare.

Today, we write One Codebase that listens to the screen size and adapts. We do this using the CSS Rule: @media.

♿ Accessibility Note: Responsiveness is Accessibility. Users with low vision often zoom their screens to 400%. If your site breaks when zoomed, it is inaccessible to them. Responsive design fixes this for free.

📖 The Textbook: The @media Rule

1. The Syntax

A Media Query is an "If Statement" for CSS.

@media (min-width: 600px) { ... }

Translation: "IF the screen is at least 600px wide (Tablet size), THEN apply these styles."

2. Mobile First Philosophy

Most beginners write Desktop CSS first, then try to squish it down for mobile. This is Backwards.

The Golden Rule: Write your default CSS for the Mobile Phone (Simple, 1-column). Then, add complexities (columns, sidebars) only when you have the screen space to verify them.

3. Standard Breakpoints

Where should you change your layout? Here are standard "Breakpoints":

  • 576px+: Landscape Phones
  • 768px+: Tablets (iPad Portrait)
  • 992px+: Desktop Monitors

👀 Look & Learn: The Shapeshifter

Resize your browser to see this code in action.

/* 1. DEFAULT (Mobile) */
body {
    background-color: white; /* Clean & Simple */
    font-size: 16px;
}

/* 2. TABLET (Triggered at 768px) */
@media (min-width: 768px) {
    body {
        background-color: lavender; /* A subtle change */
        font-size: 18px; /* Bigger screens get bigger text */
    }
}

/* 3. DESKTOP (Triggered at 992px) */
@media (min-width: 992px) {
    body {
        background-color: gold; /* Dramatic change */
    }
}
Observation:
  • The browser reads top-to-bottom.
  • It sees `white`. Then, if the screen is wide enough, it overrides it with `lavender`.
  • This is why we call it Cascading Style Sheets.

💻 Project: The Responsive Profile Card

We are going to make a business card that changes its layout completely based on the device.

📋 Directions

  1. Structure:
    • Container `.card`.
    • Image `.avatar` (A square photo).
    • Info `.info` (Name, Job Title, Bio).
  2. Default CSS (Mobile):
    • Set `.card` to display: flex; flex-direction: column; text-align: center;.
    • We want the image ON TOP, centered, and the text BELOW it. This is standard mobile design.
  3. The Query (Desktop):
    • Add @media (min-width: 700px) { ... }.
    • Inside the query, target `.card`. Change it to flex-direction: row; text-align: left;.
  4. The Result:
    • On a phone, it's a vertical stack.
    • On a laptop, it becomes a horizontal ID card (Image Left, Text Right). Magic!
Debugging Tip: If your styles aren't changing, check your <meta name="viewport"> tag in the head. If that tag is missing, mobile phones will lie about their width, and responsive design fails.
