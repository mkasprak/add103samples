📖 The Textbook: Common Patterns

1. The Grid Drop

To change a grid from 1 column to 3, you just change one line.

.container { grid-template-columns: 1fr; } /* Mobile */

@media (min-width: 768px) {
  .container { grid-template-columns: 1fr 1fr 1fr; } /* Tablet+ */
}
2. The Sidebar Drop

On Desktop, sidebars are on the side. On Mobile, they usually fall to the bottom of the page (so the main content comes first).

We achieve this by changing `flex-direction: column` (Mobile) to `flex-direction: row` (Desktop), as seen in 7A.

👀 Look & Learn: The Responsive Gallery

This is standard code for e-commerce product listings.

🔗 View Live Sample: The Responsive Gallery 
/* MOBILE (Default) - 1 Column */
.product-grid {
    display: grid;
    grid-template-columns: 1fr; 
    gap: 20px;
}

/* TABLET - 2 Columns */
@media (min-width: 600px) {
    .product-grid {
        grid-template-columns: repeat(2, 1fr);
    }
}

/* DESKTOP - 4 Columns */
@media (min-width: 1000px) {
    .product-grid {
        grid-template-columns: repeat(4, 1fr);
    }
}
Observation:
  • Notice we have THREE states.
  • The gaps stay the same (20px) but the column count scales.

💻 Project: The Responsive Photo Wall

Remember the Photo Wall from Week 6? It was stuck at 3 columns. Let's fix it.

📋 Directions

  1. Setup: Reuse your `photo-wall` code from Week 6A.
  2. Refactor (Go Mobile First):
    • Delete the old `grid-template-columns: repeat(3, 1fr);` line.
    • Replace it with `grid-template-columns: 1fr;` (Single column).
    • Check your browser. It should be a vertical stack of big images. Good for phones!
  3. Add Breakpoints:
    • Add a media query for `min-width: 600px` -> Change to `repeat(2, 1fr)`.
    • Add a media query for `min-width: 900px` -> Change to `repeat(3, 1fr)`.
    • Add a media query for `min-width: 1200px` -> Change to `repeat(4, 1fr)`.
  4. Test: Grab the corner of your browser window and drag it back and forth. Watch your grid adapt instantly. This is "Fluid" design.
