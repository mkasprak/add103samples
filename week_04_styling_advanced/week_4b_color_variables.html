📖 The Textbook: Modern Color

1. The Formats (Hex vs RGBa)
  • Hex Code (`#ff0000`): The standard for solid colors. 6 digits.
  • RGBa (`rgba(255, 0, 0, 0.5)`): Red, Green, Blue, Alpha (Transparency). Use this when you want see-through elements!
2. CSS Variables (Custom Properties)

Imagine changing a brand color on 500 pages. Nightmare? Not with variables.

Step 1: Define

:root { --primary-color: #582C83; }

Step 2: Use

h1 { color: var(--primary-color); }
3. The 60-30-10 Rule

A classic design principle:

  • 60% Neutral Background (White, Light Grey, Cream)
  • 30% Secondary Color (Brand Color)
  • 10% Accent Color (Call to Action Buttons - make them pop!)

👀 Look & Learn: Variables in Action

This is how pros structure their CSS files.

/* 1. DEFINE THE PALETTE */
:root {
    --brand-dark: #333333;
    --brand-light: #f4f4f4;
    --accent-pop: #ff4081; /* Hot Pink */
}

/* 2. APPLY THE VARIABLES */
body {
    background-color: var(--brand-light);
    color: var(--brand-dark);
}

button {
    background-color: var(--accent-pop); /* Use the variable */
    border: none;
    color: white;
}
Observation:
  • If we want to change the pink to green later, we only change it in one place (the `:root`).
  • This prevents "Frankenstein" designs where you have 15 different shades of the same color.

💻 Project: The Accessible Dashboard

You have inherited a website with terrible color choices. Your job is to fix it.

📋 Directions

  1. Setup: Create dashboard.html.
  2. The "Bad" Code (Copy this first):
    • Create an `h1` and a `button`.
    • Style the `h1` with color: #cccccc (light grey) on a white background. (Notice how hard it is to read).
    • Style the `button` with background-color: blue; color: black;.
  3. The Audit: Go to WebAIM Contrast Checker. Test your colors. They will fail.
  4. The Fix (CSS Variables):
    • Define a `:root` variable called --safe-text and find a hex code that passes WCAG AA standards (Contrast Ratio > 4.5:1).
    • Define a --button-bg variable that contrasts securely with white text.
    • Apply these variables to your elements.
  5. Gradient Bonus: Add a linear gradient to the page background: background: linear-gradient(to right, var(--brand-light), white);
