Overview

By default, HTML elements follow gravity. They stack one on top of another, from top to bottom. This is called the Normal Flow.

But what if you want a navigation bar to stick to the top? Or a caption to sit on top of an image? To do that, we must break the flow using CSS Positioning.

✨ Why this matters

Positioning is the "Special Forces" of CSS. You don't use it for everything (that's what Flexbox is for), but when you need to pin, overlay, or stick an element, nothing else will do.

🦆 Ducktor Merry Quacksalot says:
Normal flow is your friend. Before you fight the browser with position: absolute, ask: could flexbox solve this instead? It usually can — with way less code and far fewer headaches.

📖 The Textbook: Display & Position

Click below to understand how elements behave.

1. The Display Property (Block vs Inline)

Every element has a default "Display" mode:

  • Block (`div`, `p`, `h1`): Takes up the full width. Starts on a new line.
  • Inline (`span`, `a`, `strong`): Takes up only what it needs. Sits inside text.
  • None (`display: none`): Removes the element completely from the document.
2. Relative vs Absolute (The Dynamic Duo)

These two almost always work together:

  • position: relative;: "I am the reference point." (Usually set on the Parent Container).
  • position: absolute;: "I move freely inside my parent." (Set on the Child).

Rule of Thumb: If you want to overlay text on an image, the Image Container gets relative, the Text gets absolute.

3. Fixed & Sticky
  • position: fixed;: Glued to the browser window. Even if you scroll, it stays there. (Used for Chat Bubbles, Nav Bars).
  • position: sticky;: Scrolls until it hits a threshold, then sticks.

👀 Look & Learn: The Overlay

This is the most common use case: Placing a text caption ON TOP of an image.

🔗 View Live Sample: The Concert Poster 
/* 1. THE PARENT (The Frame) */
.card-container {
    position: relative; /* Defines the boundaries */
    width: 300px;
}

/* 2. THE IMAGE */
.card-image {
    width: 100%; /* Fills the container */
    display: block;
}

/* 3. THE TEXT (The Overlay) */
.card-caption {
    position: absolute; /* Breaks gravity! */
    bottom: 10px;       /* 10px from bottom */
    left: 10px;         /* 10px from left */
    
    background-color: rgba(0, 0, 0, 0.7); /* Semi-transparent black */
    color: white;
    padding: 5px;
}
Observation:
  • If we removed position: relative from the parent, the caption would fly out to the bottom of the entire webpage!
  • bottom and left are coordinate pins.

📘 Detailed Example: Relative Parent, Absolute Child

This is the core overlay pattern used in hero banners, cards, and magazine-style covers.

/* Parent container sets the positioning context */
.cover-container {
    position: relative;      /* Anchor point for absolute children */
    width: 400px;
}

/* Image fills parent width */
.cover-container img {
    display: block;
    width: 100%;
}

/* Title pinned to top center */
.cover-title {
    position: absolute;      /* Removed from normal flow */
    top: 20px;
    left: 0;
    width: 100%;
    text-align: center;
    color: #ffffff;
    text-shadow: 2px 2px 6px #000000;
}

/* Badge pinned to bottom right */
.cover-badge {
    position: absolute;
    right: 20px;
    bottom: 30px;
    background: #dc2626;
    color: #ffffff;
    border-radius: 999px;
    padding: 0.4rem 0.8rem;
}

💻 Project: The Magazine Cover

You are the editor of "Code Monthly". You need to design a clickable magazine cover using absolute positioning.

📋 Directions

  1. Setup: Create cover.html. Find a high-quality vertical portrait image (use Unsplash).
  2. Structure:
    • Create a `div` with class cover-container.
    • Inside it, place your `img` (The Cover Model).
    • Inside it, place an `h1` (The Title: "CODE").
    • Inside it, place a `div` with class `badge` (The Price/Date).
  3. The CSS (Positioning):
    • Set .cover-container to position: relative.
    • The Title: Use position: absolute; top: 20px; width: 100%; text-align: center; to center it at the top.
    • The Badge: Use position: absolute; bottom: 50px; right: 20px; to pin it to the corner. Make it round (`border-radius: 50%`) and red!
  4. Challenge: Make the image behave nicely. Give the container a fixed width (e.g., 400px) and ensure the image is `width: 100%`.
Pro Tip: Text over images can be hard to read. Use text-shadow: 2px 2px 5px black; to make your white text pop against any background.
