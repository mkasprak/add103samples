👋 Overview

It is time to build. We start by laying down the HTML structure for *all* 4 pages of your site. No CSS yet. No colors. Just pure, semantic HTML.

🦆 Ducktor Quacksalot says:
Build structure before style. Get the HTML skeleton right first — correct semantic tags, logical nesting, proper hierarchy — before you write a single line of CSS. The bones have to be right.

🎯 The Mission

Create the HTML files for your 4-page site.

  • Requirement 1: Create index.html, about.html, etc.
  • Requirement 2: Implement a robust Global Navigation (Menu) on every page.
  • Requirement 3: Ensure all content sections (Headings, Paragraphs, Image placeholders) are present.

💻 Checklist

Does every page have?
  • <!DOCTYPE html>
  • <html lang="en">
  • <meta name="viewport"...>
  • <header> with Navigation
  • <main> with unique content
  • <footer> with copyright

Detailed Example: Reusable Page Skeleton

<!doctype html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>[Page Title]</title>
    <link rel="stylesheet" href="styles.css">
</head>
<body>
    <!-- Shared global header -->
    <header>
        <h1>[Site Name]</h1>
        <nav>
            <a href="index.html">Home</a>
            <a href="about.html">About</a>
            <a href="projects.html">Projects</a>
            <a href="contact.html">Contact</a>
        </nav>
    </header>

    <!-- Unique page content goes here -->
    <main>
        <h2>[Section Heading]</h2>
        <p>[Page-specific content]</p>
    </main>

    <!-- Shared footer -->
    <footer>
        <p>Copyright 2026 [Your Name]</p>
    </footer>
</body>
</html>
