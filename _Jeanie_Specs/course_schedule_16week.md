# 📅 ADD 103: 16-Week Course Schedule
**Term:** Spring 2026 (16 Weeks)
**Cadence:** 2 Days/Week (e.g., Mon/Wed or Tue/Thu)
**Total Sessions:** 30 Lessons + Finals Week

> **Philosophy**: Teach by Example. "Watch one, Do one."
> **Last 4 Weeks**: Dedicated solely to the Final Portfolio Project.

---

## 🟢 Phase 1: Foundations (The "Code" Phase)

### Week 1: The Environment
*   **Day 1 (1A): Welcome & Hosting Access**
    *   Syllabus review.
*   InMotion hosting login and cPanel orientation.
*   Verify personal `public_html` access.
*   **Day 2 (1B): cPanel Publishing Pipeline**
*   File Manager workflow and permissions.
*   Upload first HTML page to personal live space.
*   Confirm live URL and troubleshoot 403/404.

### Week 2: Content Structure (HTML5)
*   **Day 3 (2A): Semantics & SEO**
    *   VS Code onboarding (workspace, files, code completion).
    *   `<header>`, `<nav>`, `<main>`, `<footer>` anatomy.
    *   Accessibility: Alt text, ARIA landmarks.
*   **Day 4 (2B): Content Elements**
    *   Lists (<code>ul</code>, <code>ol</code>), Links, and Images.
    *   VS Code editing workflow (split view, Emmet, formatting).
    *   File paths (absolute vs relative).

### Week 3: Styling Basics (CSS)
*   **Day 5 (3A): Intro to CSS + GitHub Start**
    *   Create GitHub account and first class repository.
    *   First commit/push from local workflow.
    *   Internal vs External stylesheets.
    *   Select by Tag, Class, and ID.
*   **Day 6 (3B): The Box Model**
    *   Margins, Borders, Padding, Content.
    *   Using Chrome DevTools to inspect the box model.

### Week 4: Typography & Color
*   **Day 7 (4A): Web Typography**
    *   Google Fonts integration.
    *   Font-size (rem vs px), line-height.
*   **Day 8 (4B): Color Theory & Accessibility**
    *   Hex codes, RGBa.
    *   Contrast checking (WCAG standards).

---

## 🟡 Phase 2: Layout & Responsiveness (The "Design" Phase)

### Week 5: Modern Layout I (Flexbox)
*   **Day 9 (5A): Flexbox Container**
    *   `display: flex`, `justify-content`, `align-items`.
*   **Day 10 (5B): Flexbox Items**
    *   `flex-grow`, `flex-wrap`, nesting flexboxes.

### Week 6: Modern Layout II (Grid)
*   **Day 11 (6A): CSS Grid Basics**
    *   `display: grid`, `grid-template-columns` (fr units).
*   **Day 12 (6B): Grid Areas**
    *   Building a Holy Grail layout (Header/Sidebar/Content/Footer).

### Week 7: Responsive Design
*   **Day 13 (7A): Media Queries**
    *   The `@media` rule.
    *   Breakpoints (Mobile, Tablet, Desktop).
*   **Day 14 (7B): Mobile-First Workflow**
    *   Writing mobile CSS first, then expanding to desktop.

### Week 8: Midterm & Review
*   **Day 15 (8A): Mid-Project Build** (In-class Lab).
*   **Day 16 (8B): Midterm Assessment** (Code Review).

---

## 🟠 Phase 3: Professional Tools (The "Pro" Phase)

### Week 9: Frameworks (Bootstrap 5)
*   **Day 17 (9A): Framework Concepts**
    *   Linking CDN.
    *   The 12-Column Grid System.
*   **Day 18 (9B): Bootstrap Components**
    *   Navbars, Cards, Modals.

### Week 10: Advanced Media
*   **Day 19 (10A): Responsive Images**
    *   `srcset`, `<picture>` tag.
    *   WebP format optimization.
*   **Day 20 (10B): Audio & Video**
    *   Native HTML5 media players.
    *   Background video techniques.

### Week 11: Interactivity (Light JS)
*   **Day 21 (11A): DOM Basics**
    *   What is the DOM?
    *   Simple `onclick` events (Toggle Menu).
*   **Day 22 (11B): CSS Animations**
    *   Transitions (`hover` effects).
    *   Keyframes basics.

### Week 12: Agent-Assisted Bootstrap Studio
*   **Day 23 (12A): Bootstrap with Agents**
*   Prompting agents for layout scaffolds and components.
*   Integrate agent output into student-authored Bootstrap pages.
*   **Day 24 (12B): Agent Output Audit**
*   Lighthouse + accessibility review of agent-generated code.
*   Refactor weak patterns and document prompt decisions.

---

## 🔴 Phase 4: The Final Project (The "Portfolio")

### Week 13: Project Planning
*   **Day 25 (13A): Concept & Wireframe**
    *   Proposal submission.
    *   Figma/Sketch/Paper wireframes.
*   **Day 26 (13B): Asset Collection**
    *   Gathering images, writing copy, color palette selection.

### Week 14: Project Build - Structure
*   **Day 27 (14A): Skeleton Build**
    *   HTML Structure implementation.
*   **Day 28 (14B): Layout Implementation**
    *   CSS Grid/Flexbox main layout.

### Week 15: Project Build - Polish
*   **Day 29 (15A): Styling & Responsiveness**
    *   Mobile check.
    *   Typography refinement.
*   **Day 30 (15B): Final QA & Peer Review**
    *   Students review each other's sites.
    *   Bug fixing session.

### Week 16: Finals Week
*   **Final Presentations**: Demo your live site to the class.
