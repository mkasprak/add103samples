## 🧭 Period 1: Course Learning Objectives
*Upon completion of the course, students will be able to:*

1.  **[Logic]** Use structured programming techniques (Sequence, Selection, Iteration) to solve problems.
2.  **[Design]** Plan programs using logic tools (Pseudocode/Flowcharts).
3.  **[Vocab]** Define key programming terms.
4.  **[Data]** Use variables to hold a variety of data types.
5.  **[Resilience]** Debug programs and handle errors.
6.  **[Modularity]** Create functions that use parameters and return values.
7.  **[Persistence]** Work with different data sources (File I/O).
8.  **[OOP]** Write simple programs implementing Classes and Objects.
9.  **[Docs]** Use comments to document program functions.

---

## 🗺️ Period 2: Course Outline & Topic Map

### Unit 1: Foundations
*   Computer programming and logic
*   Programming Languages (Compiled vs Interpreted)
*   **Debug**: Debugging strategies
*   **Data**: Variables, expressions, and statements
*   **Operators**: Mathematical and string operators
*   **Docs**: Comments and documentation standards

### Unit 2: Modularity & Control Flow
*   **Modularity**: Functions, Calling Functions, Parameters, Arguments
*   **Logic**: Conditionals (If/Else), Nested Conditionals
*   **Logic**: Boolean expressions and Logical operators
*   **Logic**: Recursion (Intro) and Advanced functions

### Unit 3: Iteration & Collections
*   **Logic**: Iteration (While/For Loops)
*   **Data**: Strings (Manipulation, Searching, Comparison)
*   **Data**: Lists (Operations, Methods, Indexing)
*   **Data**: Dictionaries (Key-Value pairs)

### Unit 4: Architecture & OOP
*   **Persistence**: Data Management (Files, Database Intro)
*   **OOP**: Classes and Objects
*   **OOP**: User-defined types, Attributes, Instances
*   **Design**: Class diagrams
