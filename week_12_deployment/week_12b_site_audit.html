💻 Code Sample

<!-- COMMON AGENT FIX: NON-DESCRIPTIVE BUTTON -->
<!-- Weak -->
<button class="btn btn-primary">Click Here</button>

<!-- Better -->
<button class="btn btn-primary" aria-label="Submit contact form">Send Message</button>

<!-- COMMON AGENT FIX: MISSING FORM LABEL -->
<!-- Weak -->
<input class="form-control" placeholder="Email">

<!-- Better -->
<label for="email" class="form-label">Email address</label>
<input id="email" class="form-control" type="email">

Detailed Audit Example: What To Check Line By Line

# AGENT OUTPUT QA CHECKLIST

# 1) Semantics
- Is there exactly one <main> landmark?
- Do headings follow a logical order (h1, h2, h3)?

# 2) Forms
- Does every input have a paired <label for="...">?
- Are input types specific (email, tel, text)?

# 3) Buttons and links
- Do CTAs use clear text (avoid "Click Here")?
- Are aria-label values meaningful when needed?

# 4) Visual quality
- Run Lighthouse and record Accessibility score.
- Fix contrast warnings and rerun.

# 5) Reflection
- Document what the agent produced.
- Document what you changed and why.
