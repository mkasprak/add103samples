Overview

Before 2012, laying out a website was a nightmare of hacks and floating elements. Then came Flexbox.

Flexbox is a one-dimensional layout engine. It is designed to take a row of items and squish, stretch, or space them out perfectly. It is the gold standard for Navbars, Image Galleries, and Button Rows.

♿ Accessibility Note: Flexbox changes the visual order of items without changing the code order. Be careful: screen readers read the code, not the visual layout.

📖 The Textbook: The Parent Container

Flexbox works on a Parent-Child relationship. Today, we focus on the Parent (The Container).

1. The Trigger (display: flex)

By default, `div`s stack vertically (Block). To make them sit side-by-side, you add this to the Parent:

.container { display: flex; }

Instantly, all direct children become "Flex Items" and line up in a row.

2. Justify Content (The X-Axis)

How do we distribute space horizontally?

  • justify-content: flex-start; (Default: Left)
  • justify-content: center; (Center)
  • justify-content: flex-end; (Right)
  • justify-content: space-between; (Push items to edges, space in middle)
3. Align Items (The Y-Axis)

How do we align items vertically?

  • align-items: stretch; (Default: Make them all same height)
  • align-items: center; (Center vertically - The Holy Grail!)

👀 Look & Learn: The Navbar

This is the code behind almost every website header you see.

🔗 View Live Sample: The Team Page 
/* THE PARENT (The Flex Container) */
nav {
    display: flex;
    justify-content: space-between; /* Logo Left, Links Right */
    align-items: center;            /* Vertical Center */
    
    background-color: #333;
    padding: 10px 20px;
}

/* THE CHILDREN (Flex Items) */
.logo { font-weight: bold; color: white; }
.links a { margin-left: 15px; color: #ccc; }
Observation:
  • space-between is the magic property here. It automatically calculates the empty space and puts it in the middle.
  • If we didn't use Flexbox, we'd have to use `float: left` and `float: right` (The Old Way).

💻 Project: The Interactive Gallery

You will build a responsive image gallery for a travel blog.

📋 Directions

  1. Setup: Create gallery.html. Find 3 images of "Destinations" (Mountains, Beach, City).
  2. HTML Structure:
    • Create a `div` with class gallery-row.
    • Inside it, create 3 `div`s with class card.
    • Inside each card, put an Image and a Caption (H3).
  3. The CSS (Parent):

    📘 Detailed Example: Flex Container Blueprint

    This example demonstrates core container settings that control alignment, spacing, and wrapping.

    /* Parent becomes a flex container */
.toolbar {
    display: flex;              /* Places children in one row by default */
    justify-content: space-between; /* Spreads items across main axis */
    align-items: center;        /* Aligns items on cross axis */
    gap: 1rem;                  /* Adds clean spacing between children */
    padding: 1rem;
    border: 1px solid #d1d5db;
}

/* On narrow screens, allow wrapping instead of overflow */
.toolbar {
    flex-wrap: wrap;
}
