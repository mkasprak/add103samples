📖 The Textbook: The Child Properties

1. Flex Grow (Greediness)

This tells an item how much extra space to eat up.

  • flex-grow: 0; (Default: Don't grow. Stay small.)
  • flex-grow: 1; (Grow to fill remaining space.)
  • flex-grow: 2; (Grow twice as fast as the others.)
2. Nesting (Boxes inside Boxes)

Can a Flex Item also be a Flex Container?

YES! This is the secret to layout.

You might have a Row (Flex). Inside the row, you have a Card. Inside the Card, you want the Button to be on the right... so you make the Card display: flex too!

3. Align Self (Rebellion)

The Parent sets the rule (align-items: center). But a Child can disobey.

align-self: flex-start; allows one item to float to the top while everyone else is centered.

👀 Look & Learn: The 2-Column Layout

A standard blog layout: A fat content column and a skinny sidebar.

/* THE WRAPPER */
.page-wrapper {
    display: flex;
}

/* THE SIDEBAR (Fixed Width) */
.sidebar {
    width: 250px;
    background: #eee;
    flex-grow: 0; /* Don't get huge */
}

/* THE CONTENT (Fluid Width) */
.content {
    background: white;
    flex-grow: 1; /* Eat ALL the remaining space! */
}
Observation:
  • No matter how wide the screen is, the Sidebar stays 250px.
  • The Content stretches filling 100% of whatever is left. This is "Fluid Design."

💻 Project: The "Hero" Split

You will build a modern "Hero Section" (Top of page banner) that splits 50/50: Text on the Left, Image on the Right.

📋 Directions

  1. Structure:
    • Wrapper div (class `hero`).
    • Left div (class `hero-text`). Contains H1, p, and Button.
    • Right div (class `hero-img`). Contains an Image.
  2. Layout (The Parent):
    • Set `.hero` to display: flex; align-items: center;.
  3. Sizing (The Children):
    • Give BOTH `.hero-text` and `.hero-img` a flex-basis: 50% (This suggests they should try to be half widths).
    • Give Text some padding so it isn't touching the edge.
  4. Nesting Challenge: Make the Button inside `.hero-text` stay stuck to the left of the text block? (Hint: It does that by default. Trick question!)
