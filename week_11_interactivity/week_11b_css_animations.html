👋 Overview

You don't always need JavaScript to move things around. CSS Transitions and Keyframes allow us to create smooth, high-performance animations directly in our stylesheets.

🎯 The Mission

Create an "Interactive Card" that animates when you hover over it.

  • Requirement 1: Use transition to smooth out a hover effect (e.g. lift up card).
  • Requirement 2: Create a @keyframes animation that runs infinitely (e.g. a spinning loader or pulsing button).
  • Requirement 3: Apply these to a "Product Card" UI component.

💻 Code Sample

/* 1. SIMPLE TRANSITION */
.card {
    background: white;
    padding: 20px;
    transition: transform 0.3s ease, box-shadow 0.3s ease;
}

.card:hover {
    transform: translateY(-10px); /* Move up 10px */
    box-shadow: 0 10px 20px rgba(0,0,0,0.2);
}

/* 2. KEYFRAME ANIMATION */
@keyframes spin {
    0% { transform: rotate(0deg); }
    100% { transform: rotate(360deg); }
}

.loader {
    width: 50px;
    height: 50px;
    border: 5px solid #ccc;
    border-top-color: #4b3190;
    border-radius: 50%;
    animation: spin 1s linear infinite;
}
🦆 Dig Deeper: Easing Functions

The "ease" in 0.3s ease is the easing function. It controls the acceleration. Try ease-in (start slow), ease-out (end slow), or cubic-bezier for custom bounces!
