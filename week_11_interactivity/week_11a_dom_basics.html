👋 Overview

HTML is the skeleton. CSS is the skin. JavaScript is the muscle. Today we dip our toes into programming by learning how to select elements on the page (The Document Object Model) and change them when a user clicks a button.

The DOM is a live model of your HTML. When JavaScript changes it, the browser instantly re-renders the page. That’s the magic behind every interactive website you’ve ever used.

💻 Code Sample

<!-- HTML -->
<button id="modeBtn">Switch to Dark Mode</button>
<p id="statusText">The lights are ON.</p>

<!-- JAVASCRIPT -->
<script>
    // 1. Select the elements
    const btn = document.getElementById('modeBtn');
    const txt = document.getElementById('statusText');
    const body = document.body;

    // 2. Define the action
    function toggleMode() {
        body.classList.toggle('dark-theme');
        
        if (body.classList.contains('dark-theme')) {
            btn.textContent = "Switch to Light Mode";
            txt.textContent = "The lights are OFF.";
        } else {
            btn.textContent = "Switch to Dark Mode";
            txt.textContent = "The lights are ON.";
        }
    }

    // 3. Listen for the click
    btn.addEventListener('click', toggleMode);
</script>

<!-- CSS -->
<style>
    .dark-theme {
        background-color: #333;
        color: white;
    }
</style>

Detailed Example: Safer Toggle with ARIA State

<button id="modeBtn" aria-pressed="false">Enable Dark Mode</button>
<p id="statusText">Theme is currently Light.</p>

<script>
    // Cache elements so we do not query the DOM repeatedly
    const modeBtn = document.getElementById('modeBtn');
    const statusText = document.getElementById('statusText');

    modeBtn.addEventListener('click', () => {
        // Toggle visual state class on body
        document.body.classList.toggle('dark-theme');

        // Determine current state after toggling
        const darkIsOn = document.body.classList.contains('dark-theme');

        // Keep accessibility state synchronized with visual state
        modeBtn.setAttribute('aria-pressed', String(darkIsOn));

        // Update visible copy to match state
        modeBtn.textContent = darkIsOn ? 'Enable Light Mode' : 'Enable Dark Mode';
        statusText.textContent = darkIsOn ? 'Theme is currently Dark.' : 'Theme is currently Light.';
    });
</script>

🦆 Dig Deeper: Where does script go?

You can put JavaScript in the <head> or at the end of the <body>. We usually put it at the end of the body (or use the defer attribute) so that the HTML elements are fully loaded before the script tries to find them.
