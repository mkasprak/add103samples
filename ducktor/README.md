# Ducktor Merry Quacksalot — Image Library

Course mascot for ADD-103: Fundamental Web Development.

## Character Description
- **Name:** Ducktor Merry Quacksalot
- **Species:** Anthropomorphic duck
- **Gender:** Female
- **Colors:** MCC purple `#582C83` and gold `#FFC629`
- **Style:** Friendly, approachable, cartoon/illustrated

## Usage in Course
All lesson pages reference her as:
```html
<img src="[URL_DUCKTOR_QUACKSALOT]" alt="Ducktor Merry Quacksalot — ...">
```
Once final images are uploaded to Canvas Files, do a find-and-replace on `[URL_DUCKTOR_QUACKSALOT]` across all lesson HTML files.

## Image Naming Convention
```
ducktor_01_welcome.png
ducktor_02_thinking.png
ducktor_03_coding.png
...
```
Use a descriptive suffix so it's clear which expression/pose each image shows.
