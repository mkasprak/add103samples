Minute 1: Project Goal

- Explain core value your site delivers

Minute 2: Structure
- Show page map (Home/About/Projects/Contact)
- Explain navigation consistency across pages

Minute 3: Design Decisions
- Explain typography choices and color palette
- Show one responsive behavior at mobile width

Minute 4: Technical Challenge
- Describe one bug you solved
- Show before/after result briefly

Minute 5: Wrap-Up
- Share live URL
- Explain one improvement you would add next
