🚑 Emergency Room: Common Issues

Stuck? specific solutions to the most common Midterm bugs:

Issue 1: "My Grid is collapsing/exploding!"

The Fix: Check your image sizes. If you put a 4000px image into a grid cell without setting width: 100% in CSS, it will force the column to expand infinitely. Always constrain your media!

Issue 2: "My Mobile View looks weird."

The Fix: Did you write Mobile First? If you wrote complex Desktop grid code without a media query, your phone is trying to render 4 columns. Wrap your complex layout code in @media (min-width: 768px) { ... }.

Issue 3: "My Navigation Links are vertical."

The Fix: Remember to apply display: flex to your `nav ul` (the list container), not the `nav` itself. Then use gap: 20px to space them out.

📘 Detailed Example: Midterm Bug-Triage Script

Midterm Triage Loop

1) Reproduce the bug
    - Write what you clicked
    - Write what you expected
    - Write what happened instead

2) Inspect the element
    - Check class names and path typos
    - Confirm CSS file is linked correctly

3) Apply one small fix
    - Save
    - Refresh
    - Retest

4) Commit the fix
    - Document what was broken and what changed

✅ Pre-Flight Checklist

Before you submit to the Canvas Assignment folder "Midterm Project", verify:

  • 🔲 W3C Validated: No Red Errors in HTML or CSS.
  • 🔲 Relative Links: All your links work locally (e.g., `href="about.html"`, NOT `href="C:/Users/Steve/items/about.html"`).
  • 🔲 Images Folder: Are your images inside an `images/` folder? Is the path correct?
  • 🔲 Git Push: In VS Code Terminal: git add . && git commit -m "midterm final" && git push. Then in cPanel Git Version Control → Manage → Update from Remote. Confirm your live URL loads all pages.
