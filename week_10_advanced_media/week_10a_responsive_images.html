🦆 Module 10A: Responsive Images

One Size Does Not Fit All

⏱️ Time: 45 Minutes | 🏆 Points: 10 | 📅 Due: Sunday 11:59PM

👋 Overview

Images are the heaviest part of any website. If you load a 4K desktop photo on a tiny mobile screen, you are wasting the user's data and slowing down your site. Today, we learn to serve the "just right" image for every device using srcset and the <picture> element.

🎯 The Mission

Create a "Gallery" page that serves different image resolutions based on the screen size.

  • Requirement 1: Use srcset to serve 3 different sizes of an image (small, medium, large).
  • Requirement 2: Use the <picture> tag for "Art Direction" (changing the crop on mobile).
  • Requirement 3: Convert one image to WebP format for optimization.

💻 Code Sample

<!-- METHOD 1: Resolution Switching (Same image, different sizes) -->
<img src="dog-medium.jpg"
     srcset="dog-small.jpg 500w,
             dog-medium.jpg 1000w,
             dog-large.jpg 2000w"
     alt="A cute puppy">

<!-- METHOD 2: Art Direction (Different image entirely) -->
<picture>
    <source media="(max-width: 600px)" srcset="dog-close-up-portrait.jpg">
    <source media="(min-width: 601px)" srcset="dog-wide-landscape.jpg">
    <img src="dog-fallback.jpg" alt="A cute puppy">
</picture>

Detailed Example: Production-Ready Responsive Image Block

<!-- Use picture for art direction + modern format fallback -->
<picture>
        <!-- Small-screen crop in WebP for faster loading -->
        <source media="(max-width: 600px)" srcset="images/hero-mobile.webp" type="image/webp">

        <!-- Large-screen crop in WebP -->
        <source media="(min-width: 601px)" srcset="images/hero-desktop.webp" type="image/webp">

        <!-- Fallback image for browsers with limited format support -->
        <img
            src="images/hero-desktop.jpg"
            srcset="images/hero-mobile.jpg 600w, images/hero-desktop.jpg 1400w"
            sizes="(max-width: 600px) 100vw, 1400px"
            alt="Students collaborating around laptops in design studio"
            loading="lazy"
        >
</picture>

🦆 Dig Deeper: WebP vs JPG

WebP is a modern image format that provides superior lossless and lossy compression for images on the web. It is now supported by all major browsers and is typically 25-30% smaller than a comparable JPEG.
